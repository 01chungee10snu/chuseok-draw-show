## 전체 진행

합성 명단으로 **240 → 120 → 59 → 27 → 14 → 7 → 4 → 2 → 1**을 진행했습니다. 7명부터 이름을 공개했고 이전에는 그룹만 표시했습니다.

무대 순서: 핀볼 바운스 → 라이트 그리드 → 라스트 게이트 → 중력 계단 → 오비트 랠리. 결선은 스포트라이트 → 트윈 레이스 → 파이널 마블입니다. 첫 전체 흐름의 결선은 움직임 줄이기를 검증했고, 별도 명단에서 정상 속도의 세 결선도 확인했습니다.

당첨 기록은 한 번만 생겼습니다. 다음 추첨은 해당 당첨자를 제외한 **239명**으로 시작했습니다. 일시정지 중 물리 진행도가 유지되고 이어서 진행됐습니다.

## 오류 후 동일 결과 재개

Canvas 재생 함수가 실제로 예외를 던지도록 오류를 주입했습니다. 그 결과 **14명·확정 결과·대기 단계**가 유지됐고, 다음 버튼은 “연출 다시 보기”로 바뀌었습니다. 재시도 후 10명 공개가 완료됐습니다. 해당 세션의 `draw_committed` 기록은 **정확히 1개**였으며 재추첨은 없었습니다.

첫 오류 주입 스크립트는 Vite의 다른 모듈 인스턴스를 바꾸어 실제 인스턴스에 적용되지 않았습니다. 이를 앱 실패로 오인하지 않고 활성 Canvas에 주입하는 방식으로 수정해 위 결과를 확인했습니다.

## 범위와 운영

Chrome의 합성 데이터 검수입니다. Safari·Firefox 및 실제 행사 프로젝터에서의 검수는 수행하지 않았습니다. 행사 전 사용 기기에서 명단과 소리를 리허설하세요. 네트워크가 느리거나 WASM을 사용할 수 없으면 정적인 공개 연출을 사용하며 추첨 결과는 보존됩니다. 연출 종료 제한은 무한 대기를 방지하기 위한 장치이며 골인 순서가 추첨을 결정하지 않습니다.

브라우저 새로고침 시 명단과 당첨 기록이 지워집니다. 행사 문구·테마 등 설정만 이 브라우저에 저장되며, 사용자 배경은 다시 선택해야 합니다. 운영자가 원본 명단의 중복 등록 여부를 확인하고 결과를 내보내야 합니다.

기존 v0.7 보고서의 15/15와 달리 재확인 당시 원본은 14/15였습니다. 원본 문서는 역사적 기록으로 유지하며 본 문서가 v1.0의 검수 기준입니다.
